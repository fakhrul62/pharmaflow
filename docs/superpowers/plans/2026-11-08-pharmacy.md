# Pharmacy workspace Implementation Plan

> **For agentic workers:** Use subagent-driven-development for focused implementation and review. The user explicitly authorized full execution without questions.

**Goal:** Deliver a functional redesigned pharmacy management application.

**Architecture:** React/Vite frontend consumes a NestJS REST API. Prisma/PostgreSQL holds authoritative records; services own transactional stock workflows.

**Tech Stack:** React, TypeScript, Vite, NestJS, PostgreSQL, Prisma, TanStack Query/Table, Tailwind, Radix UI, React Hook Form, Zod, Recharts.

**Spec:** docs/superpowers/specs/2026-11-08-pharmacy-design.md

## Global Constraints

- Work only in the new pharmadashbaord directory; preserve the reference.
- Server-authoritative inventory and money, persistent writes and server-enforced permissions.
- Responsive, keyboard-accessible UI with visible error and loading states.
- Record payments only; no external payment processor or email service assumed.

## Review Focus

- Concurrent checkout cannot oversell a batch; negative quantities rejected.
- Expired and quarantined batches cannot be sold.
- Duplicate receiving or returning cannot change stock twice.
- Reloading preserves mutations; authentication and staff restrictions enforced.
- Narrow screens, keyboard navigation and empty/error states remain usable.
